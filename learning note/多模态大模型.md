# Patch Embedding

通过下列变换将 $\mathbf p_i$ 变成大模型处理的 $\mathbf z_i$ 

$$\mathbf z_i=W\mathbf p_i+\mathbf b$$


然后再将Patch的空间信息纳入考虑。

$$\mathbf h_i=\mathbf p_i+\mathbf e_i$$

之后，我们令 $q, k, v$ 分别代表每个patch的查询、键值和信息，进行匹配。就相当于我要去图书馆找书，我要找书的目的是学习机器学习，也就是 $q$ ，然后每本书的书名和目录就是 $k$ ，我通过比较 $q$ 和 $k$ 来找到我想要的书，也就是计算匹配分数，进而决定我在每本书上花费多少的精力。最后更新 $y_i = \sum_{j} \alpha _{i,j}v_j$ ，其中 $\alpha$ 表示权重。


$$\operatorname{Attention}(Q,K,V) = V \left [\operatorname{softmax} \left( \frac{Q^\top K}{\sqrt{d_k}} \right)^\top\right ]$$
